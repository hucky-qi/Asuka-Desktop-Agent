# 测试与验证边界

[导航](README.md)

从项目根目录执行：

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python run_tests.py
```

默认离线：先19项安全预算/隔离检查，再公开HTTP黑盒。外部模型/搜索/EventKit均为隔离模拟依赖；`safety.launch`在导入业务前安装socket/subprocess审计，只允许显式模拟端口，错误地址、未覆盖嵌套路径、依赖不可用时停止，不回退Ollama/百度。人工样本由运行器生成，数据库和账本在隔离副本，不读取正式用户库。预期JSON冻结并校验哈希，失败记录不改成预期。首次发布验证结果在本页末尾追加。

可选前端状态单测：`node --test live2d/state-controller.test.mjs`，不需要SDK。`acceptance/blackbox-concurrency/run.py --serve-ui`开放隔离浏览器测试页；需用同一虚拟环境运行，不能把UI模拟当成原生GUI。历史私人验收目录未发布，只提取运行代码、冻结预期和人工样本生成器，测试结果/日志默认忽略。

## 真实验证默认关闭

快速入口不接受真实参数；policy默认enabled=false、查询/调用预算0。真实验证须单独明确授权、指定本地endpoint、使用`acceptance/test-safety/safety.py`的RealGate在每个查询和每个内部HTTP模型调用前原子预占；并发不能超额，失败不退还预算，关闭剩余授权。本公开包不提供绕过门禁的自动真实批量命令。不把打开普通用户入口作为开发预算旁路。模型下载/百度请求/私人日历写入均不属于默认测试。

## 覆盖与缺口

- 自动HTTP：聊天会话/追问/重置、文件筛选/排序/身份、并发取消、日历外部依赖状态、联网模拟计数与重启持久化。
- 浏览器：另行运行模拟页面，覆盖composition事件、草稿/隐藏恢复、选择与等待展示；合成composition不是系统IME。
- 历史真实模型：embedding参与证据存在；复杂并发37.4秒/partial0失败保留，未因发布而宣称修复。少量日历预览有成功与失败；不累计重叠套件为独立总数。
- 用户人工：原机IME选词、拖动边界、日历读取和创建有成功记录，公开干净安装未重做。
- 未验收：Windows、真实Mac快捷键、日历修改写入/确认、最新自动弹窗原生视觉/焦点；浏览器/编译不替代这些项目。

发布检查不读取用户剪贴板，不启动私人日历，不做真实模型/联网调用。内存数字是历史观测，约2秒RSS采样，非绝对峰值/整机最小要求。发布版应用构建和无模型回退的实际覆盖在验证记录里区分。

## 首次公开包验证（2026-10-16）

干净虚拟环境依赖安装通过；安全隔离19项、公开HTTP黑盒11组、Node状态控制器14项通过，分别记录，不相加冒充独立产品用例。无Key启动、网页/气泡页面、人工编号PDF搜索通过，外部模型/搜索请求0。Swift人物和.app启动器已编译，独立蓝色无模型窗口取得原生就绪标记；鼠标、焦点、完整.app双击/系统日历授权未在此副本重新验收。Windows与用户合法SDK/模型构建未实测，无素材Web与蓝色回退不依赖它们。

首次运行保留两类测试夹具失败：快速文件任务结束在状态轮询之间；隔离器按设计阻止真实系统open，使旧选择测试拿不到完成事件。修正为公开请求时间交集＋剩余任务状态断言，以及仅允许人工fixture路径的外部HTTP open模拟；没有关闭审计、降低身份断言或修改搜索业务。文件取消场景改用有明确延迟的模拟模型任务，避免把已经完成的结果错误认作取消后回写。合成账本取代原机账本。首次失败原件仅保留本机，含本地路径的原始日志不发布。

发布源码、暂存区和全部提交使用Gitleaks及定向检查；另在本机内存中比较已知凭据，报告只给结论，不输出原值。扫描未发现不代表绝对无泄漏。未发布私人报告、截图、正式数据或第三方SDK/角色资产。`tools/verify_release.py`可重跑无Key隔离启动；`--native-smoke`须先自行编译`.desktop_pet`，只验证独立无模型窗口就绪，结束后退出该测试窗口，不替换原桌面入口。

桌面启动/构建安全单测7项通过；.app在发布副本独立目录生成并签名验证，未替换用户桌面入口。首发没有运行付费API、真实模型、embedding或私人日历写入。
