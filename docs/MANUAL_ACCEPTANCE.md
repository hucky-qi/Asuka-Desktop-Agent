# 集中人工验收

使用专用样本文件与测试日程，不上传私人正文。先按README安装无Key网页，再自行配置需要的模型。桌面验收：点击/拖动/边缘、输入法和快捷键、停止/重置、隐藏恢复草稿、回答完成自动显示。文件：找名称与正文不同的样本→筛选排序→可信选择→正文授权→问答→取消。记忆：记录/纠正/重置/重启/查询/遗忘与撤销云端许可。日历：系统许可恢复→预览→纠正/取消，真实写入必须本人核对具体对象确认。语音：手动安装资产→主应用点击麦克风→停止→编辑→手动发送，权限拒绝和恢复分开验证。提醒用明确标注测试入口，通知权限由用户处理，睡眠/无页面/生成中返回最新任务待单独验收。不用浏览器或mock代替原生。

## macOS预览版集中验收补充

先按README在独立目录无Key启动，检查缺配置、文字输入和无SDK回退；需模型时再自行配置。原机已有语音缓存不代表新机器下载通过，先--status，必要时明确--install。原生工具定位不可用，仍需本人核对点击、焦点、中文选词、快捷键、隐藏恢复、自动回答显示及麦克风。日历真实写入/删除只在核对具体事件后确认，正式提醒保持原开关，不用真实日程作为批量验收样本。

## 相对时间和同预览提醒（2026-10-23）

先使用专门测试事项，勿确认不愿保留的事件。输入“过两小时帮我安排一下”→补充事项→核对预览未重新起算；再明确纠正为“一个半小时后”→只改时长→核对标题、目标和时长。取消应零写入。授权恢复后目标应保持，过期则明确拒绝。

普通创建的“同时提醒我”应未选；选中后默认30分钟。尝试20分钟后的事件选30：应阻止并保留时间；0表示开始时，负数/小数/指数/空值/超大值均不允许。等待10秒检查范围刷新；修改时间需重新预览。开关关闭时用“打开提醒设置”进入现有设置，不能自动开启或丢失预览。

核对具体事项、日历和时刻后，只有你明确点击确认才允许真实写入。成功应展示自然日期；日历创建和助手提醒分别反馈，提醒失败/关闭不得说全部成功。总开关仍保留你的原值，系统日历alarm不改变。刷新/重启后旧确认可能失效，应查询原操作，不能重复创建。

原生焦点/中文选词、自动弹窗、隐藏恢复、睡眠/时区切换及真实通知本轮未验收；浏览器合成截图仅证明隔离界面，不替代这些项目。

## 2026-10-24 稳定预览更新

聊天来源闭环：先用合成内容，在记忆设置开启当前入口本地保存；需要整理时另行允许云端来源，再开启或手动运行一批。核对候选原文和角色，编辑明确对象后采纳；重置后检查未许可不外发、逐条许可后召回、撤销/遗忘后停止召回。不要用私人内容做首次验收。默认30天、停止/删除/遗忘语义见README。原生IME/齿轮返回/隐藏恢复及下一次自然提醒后返回最新聊天仍待集中人工核对，不为验收自动发通知。
