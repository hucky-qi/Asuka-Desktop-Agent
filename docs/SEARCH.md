# 文件助手

[导航](README.md) · [安装与使用](../README.md)

网页“文件助手”是自然语言入口，“高级筛选”是条件表单；二者共享结果与上下文，文件选择绑定身份。现有名称/目录/内容工具、关键词与embedding融合、有限候选复核均随源码发布。桌面闲聊与文件会话隔离。

类型、目录、时间、大小、完整标识是硬条件，主题独立相关性证据不能由PDF等类型词替代。A1完整证据与展示片段解耦；A2完整字母数字标识、AND/OR与同文件跨分块证据保留。图片/视频只用名称、目录、元数据，不声称识别画面。

基础范围与忽略配置见[settings.py](../settings.py)，自定义目录通过侧栏“添加目录”，持久化见[preferences.py](../preferences.py)。只能选允许根目录内已有子目录；真实权限仍受系统限制。没有索引时名称检索可用，语义覆盖不完整须提示。索引由用户显式更新，增量复用未变文件；自动更新默认关闭，开启后间隔15分钟。库为项目内`.semantic_index.sqlite3`，不要提交或重建用户库来做发布测试。

速度目标普通5秒、复杂约15秒（含排队）不是保证。聊天与语义复核竞争时历史出现37.4秒及partial/0结果；部分主题排序仍有误报/漏报。模型调度仅协调本项目，不能准确区分Ollama内部排队与计算；取消前端不证明服务立即释放算力。首卡与完整回答耗时分开，不能将暖搜索与旧完整回答混比。文件扫描/结果/正文长度有安全上限，见settings；不宣称覆盖整台电脑。

2026-10-16：发布稳定实现，未合入日历候选，也未调整搜索规则。公开回归使用人工野餐/项目编号等样本，不包含私人正文或正式索引。
